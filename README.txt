PAYFLOW FULL EDUCATIONAL DEMO
No login, Firebase or backend. Data is localStorage only.

FUNCTIONS:
Home dashboard, wallet balance with PIN, send money, scan & pay camera,
receive QR, demo add money, transaction history, recharge/bill demo sections,
profile/settings placeholder, success sound, PWA/Add to Home Screen.

PIN: any non-empty value is accepted (demo behavior).
QR camera requires HTTPS/localhost and camera permission.
External QR libraries are loaded from CDN.

This is an educational simulation and does not process real UPI/bank payments.
